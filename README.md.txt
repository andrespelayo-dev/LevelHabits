# LevelHabits

A gamified personal development tracker designed to help users visualize long-term growth through skills, habits, XP, and progression systems.

## Overview

LevelHabits is a personal RPG-style growth tracker where users create skills, log practice sessions, earn experience points, and visualize their development over time.

## Technology Stack

Frontend:
- React
- TypeScript

Backend:
- C#
- ASP.NET Core
- Entity Framework Core

Database:
- SQLite

Currently in active development.
