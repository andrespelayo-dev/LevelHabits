# LevelHabits Project Vision

## Overview

LevelHabits is a gamified personal development tracker that helps users build skills through consistent practice.

## Problem

Traditional habit trackers often focus only on completing tasks. LevelHabits focuses on long-term growth by allowing users to visualize skill development.

## Core Features

Version 1:
- Create skills
- Log practice sessions
- Earn XP
- Level progression
- Prestige system
- Progress visualization

## Future Features

- Character customization
- Achievement system
- Skill relationship map
- Cloud deployment

## Learning Goals

This project is designed to strengthen understanding of:
- Full-stack development
- React
- C#
- ASP.NET Core
- Databases
- APIs
- Software architecture
